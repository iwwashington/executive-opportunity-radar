# Irving Washington Personal Site Prototype

This is a temporary personal-site prototype living inside the Executive Opportunity Radar repository so it can be tested without disrupting the radar.

## Live path

If GitHub Pages is serving the repository root, the prototype should be available at:

https://iwwashington.github.io/executive-opportunity-radar/personal-site/

## Current direction

- Personal site first — not a KFF site and not a job-search microsite.
- Working hero line: **People. Ideas. In Motion.**
- Strong executive evidence lives in the Work section.
- Governance is prominent.
- Speaking stays visible but is not the organizing identity.
- Life is intentionally present: travel, fitness, food and family.
- Only verified professional claims are used.

## Photo status

The current build uses:
- a public KFF portrait as the hero;
- a public ONA event photo for speaking;
- placeholders for travel, fitness, food and family.

Replace those placeholders with Irving's actual photos before treating this as a finished site.

## Fact-check guardrails

Do not add these claims without stronger verification:
- "doubled ONA's size, scope and reach";
- "doubled ONA's budget as CEO";
- unsupported staff-growth claims;
- ASAE Investment Committee chair;
- KFF team size / operating budget;
- personal credit for AJP capital raised or KFF grants;
- Ball State Foundation board role before it is publicly current.
